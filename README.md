# Full-Stack CRUD Lab 🚀

An ongoing full-stack web application built for learning and testing modern web development workflows, featuring a React frontend and a Node/Express backend.

## 🛠️ Tech Stack

### Frontend
* **React** (with TypeScript & React Router)
* **Tailwind CSS** & **shadcn/ui** for styling and components
* **Axios** for API requests

### Backend
* **Node.js** & **Express**
* **Prisma ORM** (Database Management)
* **Redis** (Caching / Session management)
